# European Football Tactical Analytics Dashboard ⚽📊

## 📌 Project Overview
An interactive Power BI dashboard designed to analyze attacking output, possession metrics, and tactical efficiency across the top 5 European football leagues. 

## 🛠️ Tools & Technologies Used
* **Power BI:** Data visualization, DAX, conditional formatting.
* **Power Query:** ETL processes, data cleaning, and handling null values.
* **Data Modeling:** Constructed a relational Star Schema utilizing `Dim_Clubs` and `Fact_SquadStats` tables.

## 🧠 Key Insights
* **Tactical Overperformance:** Identified teams heavily outperforming their expected metrics.
* **Attacking Tiers:** Utilized conditional formatting to segment clubs into elite, average, and struggling attacking tiers based on a 90-minute median.

## 📂 Dataset
The raw data was sourced from FBref, detailing team-level metrics for the 2023/2024 season.
